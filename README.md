# سمايل جو — صفحة متجر احترافية عالية التحويل

صفحة عربية RTL جاهزة للنشر، مبنية بـ HTML/CSS/JS خالص بدون أي مكتبة خارجية.
مصمّمة على مبادئ من يُعتدّ برأيهم في تصميم الويب والتحويل، وليست قالباً زخرفياً.

## كيف تشغّلها

```bash
npx http-server -p 8080
# ثم افتح http://localhost:8080
```

أو ارفع الملفات كما هي إلى أي استضافة ثابتة (Netlify / Vercel / Cloudflare Pages / استضافتك الحالية).

## بنية الملفات

```
index.html            الصفحة كاملة — كل نص قابل للاستبدال ومُعلَّم بتعليق عربي
assets/css/styles.css نظام التصميم: الألوان، المسافات، الاستجابة، RTL
assets/js/main.js     المنتجات، السلة، البحث، الأسئلة الشائعة، التفاعلات
```

## ما الذي أُنجز فعلياً في هذه الصفحة

| العنصر | المبدأ وراءه |
|---|---|
| هيرو بجملة واحدة + زر رئيسي واحد | قاعدة الخمس ثوانٍ (Steve Krug): الزائر يمسح ولا يقرأ |
| شريط ثقة بأربعة عناصر أسفل الهيرو | إزالة أكبر أربعة اعتراضات قبل أن تُطرح |
| الدفع عند الاستلام والإرجاع المجاني في المقدمة لا في الفوتر | أكبر مخاوف المشتري في السوق المحلي |
| شريط "أضف للسلة" ملتصق على الموبايل | Mobile First — الموبايل هو الشاشة الأساسية لا الاستثناء |
| شريط تقدّم نحو الشحن المجاني داخل السلة | يرفع متوسط قيمة الطلب |
| زر واتساب عائم + زر "أرسل الطلب على واتساب" برسالة معبّأة تلقائياً بمحتويات السلة | أقوى قناة بيع محلياً؛ يلتقط من لا يُكمل الدفع |
| تقييمات بصور ومدن حقيقية و"شراء موثّق" | الدليل الاجتماعي (Cialdini) أقوى من أي ادّعاء ذاتي |
| مؤشر مخزون صادق يظهر فقط عند الكمية المنخفضة | لا عدّاد تنازلي وهمي — الإلحاح المزيّف يقتل الثقة |
| بحث فوري مع صور أثناء الكتابة | تقليل الحمل الذهني (Nielsen) |
| أسئلة شائعة، كل سؤال فيها اعتراض يمنع شراء | التوصيل، الدفع، الإرجاع، الأصالة |
| بيانات منظّمة `Store` + `AggregateRating` | يجعل جوجل يعرض النجوم في نتائج البحث |
| بطاقة مشاركة OG | رابطك يظهر بصورة عند إرساله على واتساب |
| صفر مكتبات خارجية، SVG مضمّن، خط واحد بـ `display=swap`، `preconnect` | LCP منخفض — كل ثانية تأخير تأكل من التحويل |
| خصائص CSS منطقية (`inline-start` بدل `left`) | RTL صحيح فعلياً، لا مقلوب يدوياً |
| احترام `prefers-reduced-motion`، تركيز لوحة مفاتيح ظاهر، `aria-expanded` | إتاحة أساسية لا رفاهية |

## ما تحتاج تغييره قبل النشر

1. **رقم الواتساب** — في `assets/js/main.js` ضمن `CONFIG.whatsapp`، وفي روابط `wa.me` داخل `index.html` (ابحث عن `962790000000`).
2. **المنتجات** — مصفوفة `PRODUCTS` في أعلى `main.js`. الاسم، السعر، السعر القديم، التقييم، المخزون، الشارة.
3. **الصور** — كل مربع رمادي متدرّج يحمل `class="ph"` هو موضع صورة. استبدله بـ:
   ```html
   <img src="assets/img/product-1.webp" width="800" height="800" alt="وصف المنتج" loading="lazy" decoding="async">
   ```
   لصورة الهيرو فقط استخدم `fetchpriority="high"` وأزل `loading="lazy"` — هي عنصر الـ LCP.
4. **النصوص** — العنوان، الوصف، الأسئلة، التقييمات. التقييمات يجب أن تكون حقيقية؛ المزيّفة تُكتشف وتُفقدك ما بنيته.
5. **رابط الدفع** — `CONFIG.checkoutUrl`.
6. **الهوية** — غيّر `--brand` و`--ink` في أول `styles.css` ويتغيّر الموقع كله.
7. **حدّ الشحن المجاني** — `CONFIG.freeShippingAt`.

## نقلها إلى منصتك الحالية

- **سلة / زد**: انسخ الأقسام كمكوّنات داخل القالب، واربط `PRODUCTS` بمخرجات المنتجات بدل المصفوفة الثابتة.
- **شوبيفاي**: كل قسم يصير `section` بملف `.liquid`، و`PRODUCTS` تُستبدل بحلقة `{% for product in collection.products %}`.
- **ووكومرس**: الأقسام كـ template parts، والمنتجات عبر `WP_Query` أو الـ REST API.

الـ CSS والـ JS ينتقلان كما هما في الحالات الثلاث — لا اعتماد على أي منصة.

## ما لم يُنجَز بعد (الخطوة التالية)

- **صور حقيقية** — أرخص استثمار بأعلى مردود بصري؛ الصفحة الآن بمواضع صور فقط.
- **القياس**: GA4 + Meta Pixel + TikTok Pixel مع أحداث `view_item` و`add_to_cart` و`purchase`، و Microsoft Clarity (مجاني) لخرائط حرارية تريك أين يتوقف الزوار فعلاً.
- **صفحة منتج مفردة** بمعرض 6–8 صور وفيديو 15 ثانية وجدول مقاسات.
- **استرجاع السلة المتروكة** عبر واتساب أو إيميل.
- **حصر التركيز داخل السلة الجانبية** (focus trap) لإتاحة أكمل.
- **صفحة "من نحن"** بوجه حقيقي وقصة — تحوّل المتجر من مجهول إلى شخص.

## التحقق الذي جرى فعلياً

اختُبرت الصفحة في Chromium على مقاسي 1280×900 و390×844:
الاتجاه RTL صحيح، 8 بطاقات منتج تُبنى، الإضافة للسلة تفتح السلة وتحدّث العدّاد والمجموع وشريط الشحن،
رسالة واتساب تُبنى بمحتويات السلة، البحث الفوري يرشّح، الأكورديون يعمل، شريط الشراء يظهر على الموبايل،
لا تمرير أفقي على أي من المقاسين، ولا أخطاء جافاسكربت في الكونسول.
